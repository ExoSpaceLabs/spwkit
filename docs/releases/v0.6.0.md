# SpWKit v0.6.0

SpWKit v0.6.0 completes the public software boundary for hardware-backed SpaceWire integrations while keeping application code on the same `spw_port_*` API used by the virtual backends.

## Highlights

- portable `SPW_BACKEND_DRIVER` callback/configuration contract;
- DMA-capable zero-copy ownership mapping through `spw_buffer_t`;
- deterministic host reference-driver and no-heap/freestanding coverage;
- accepted CCSDSPack `v2.0.0` interoperability baseline at commit `c2f318c330c564429bcc565a8acbff22728b2851`;
- installed-package CCSDSPack PUS-C TC/TM transport over VSPW-TP/UDP and Linux DEVICE/VSPD;
- deployment-shaped two-node Docker Compose interoperability fixture;
- physical STM32H755 Cortex-M7 DMA/cache qualification using the public driver boundary.

## STM32H755 qualification

The NUCLEO-H755ZI-Q phase-7 board test completed with:

```text
magic                   = 0x53505736
phase                   = 0x0000700d
result                  = 0x00000000
sync_to_device          = 1
sync_from_device        = 1
dma_transfers           = 2
tx_packets              = 2
rx_packets              = 2
reset_stale_invalidated = 1
RESULT: PASS
```

This proves the MCU DMA/cache/zero-copy ownership boundary, including invalidation of a pre-reset buffer handle. It is not SpaceWire electrical/PHY interoperability evidence.

## Distribution

The tag-triggered Release workflow validates that the tag is the exact `main` head and that project/API/changelog/consumer versions agree. It then builds Debian packages for `amd64`, `arm64`, `armhf`, and `riscv64`, publishes SHA-256 sidecars, and publishes the multi-platform GHCR runtime image.

## Scope boundary

v0.6.0 does not publish proprietary RTL, register maps, DMA descriptor layouts, internal bus/clock/reset/interrupt architecture, or electrical design. Physical FPGA/SpaceWire interoperability remains a later hardware-validation layer.

See [`../v0.6-scope.md`](../v0.6-scope.md) and [`../hardware-acceptance.md`](../hardware-acceptance.md) for the public boundary and future HIL criteria.
