# SpWKit v0.5.1

SpWKit v0.5.1 is a maintenance release on the v0.5 line. It does not change the C runtime ABI, backend behavior, VSPW-TP wire format, VSPD contract, or hardware evidence boundary.

## Fixed

- completes the optional C++17 `spwkit::Port` convenience wrapper for the workspace-requirement and zero-copy ownership operations already present in the v0.5.0 public C API;
- exposes `Buffer`, `BufferView`, and `WorkspaceRequirements` aliases without introducing a second ABI or backend implementation;
- preserves C ownership semantics, including pointer clearing after successful submit/release operations;
- adds C++ compile coverage for the additional forwarding surface;
- adds a simulator-backed C++ zero-copy example covering acquire, fill, submit, receive, release, reclaim, and release;
- extends the existing loopback C++ example to verify capability-gated `SPW_ERR_UNSUPPORTED` behavior.

## Compatibility

- C ABI: unchanged;
- C++ wrapper: additive, header-only;
- SONAME major: unchanged;
- supported hosted/runtime backends: unchanged from v0.5.0;
- release architectures: `amd64`, `arm64`, `armhf`, and `riscv64`;
- physical SpaceWire/FPGA HIL: still not claimed.

The maintenance branch is `release/0.5`; ongoing v0.6 development remains separate.
